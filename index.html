Setup Guide — Already configured! (JSONBin.io)

Everything runs inside your CBTS Microsoft 365 account — SharePoint stores the data, Power Automate is the API. Free with your existing M365 license. Do this setup once, then share the HTML file with your team.

Before you start — confirm you can open these two URLs on your laptop:
• cbts.sharepoint.com (SharePoint)
• make.powerautomate.com (Power Automate)
1
Create SharePoint Lists
Go to your SharePoint site → click + New → List. Create these 5 lists:

List 1: TeamEntries — add these columns (all Single line of text unless noted):
• EntryDate, Tech, TicketNo, OrderNo, OrderType, OrderRemarks
• AvayaDept, AvayaReason, AvayaCaller, AvayaRemarks

List 2: TechMembers — column: TechName
List 3: Remarks — columns: RemarkText, RemarkType, UsageCount (Number)
List 4: Departments — column: DeptName
List 5: CallReasons — column: ReasonName
Add default values to Departments and CallReasons lists manually.
2
Open Power Automate
Go to make.powerautomate.com and sign in with your CBTS Microsoft 365 account.
3
Create Flow 1 — Get Entries
Click + New flow → Instant cloud flow.
Trigger: When an HTTP request is received → Method: GET.
Add action: SharePoint → Get items → pick your site → List: TeamEntries → Top Count: 5000.
Add action: Response → Status: 200 → Body:
{"entries": @{outputs('Get_items')?['body/value']}}
Headers: Content-Type: application/json and Access-Control-Allow-Origin: *
Save. Copy the HTTP POST URL shown in the trigger — paste it into the dashboard HTML as PA_GET_ENTRIES.
4
Create Flow 2 — Add Entry
Trigger: When an HTTP request is received → Method: POST.
Request body JSON schema (click "Use sample payload"):
{"action":"addEntry","entry":{"date":"","tech":"","ticketNo":"","orderNo":"","orderType":"","orderRemarks":"","avayaDept":"","avayaReason":"","avayaCaller":"","avayaRemarks":""}}
Add action: SharePoint → Create item → List: TeamEntries → map each field from triggerBody()?['entry'].
Add action: Response → Body: {"success":true,"id":@{outputs('Create_item')?['body/ID']}}
Save and copy the URL → paste as PA_ADD_ENTRY.
5
Create remaining flows (3 to 13) the same way
Each flow follows the same pattern: HTTP trigger → SharePoint action → Response.
• Flow 3 Delete Entry: SharePoint → Delete item → ID from triggerBody()?['id']
• Flows 4–6: Same pattern for TechMembers list (Get items / Create item / Delete item)
• Flow 7: Get items from Remarks list, sorted by UsageCount
• Flows 8–13: Same pattern for Departments and CallReasons lists
Copy each flow URL and paste into the matching variable in the dashboard HTML.
6
Paste all 13 Flow URLs into the dashboard
Open cbts-team-dashboard.html in Notepad or VS Code.
Find the section at the top of the script that starts with var PA_GET_ENTRIES = "";
Paste each copied URL between the quotes for the matching variable.
Save the file.
7
Share with your team
Upload cbts-team-dashboard.html to a SharePoint document library or shared Teams channel.
Everyone opens the file in their browser — all data goes to the same SharePoint lists automatically.
Free with M365 — SharePoint + Power Automate standard connectors are included in your CBTS Microsoft 365 license.
No Google needed — everything lives inside your CBTS tenant.
IT-friendly — no external services, no Azure registration required.
Data in SharePoint — managers can view all entries directly in the SharePoint list at any time.
Tip — if you get CORS errors when testing, add Access-Control-Allow-Origin: * to every Response action header.
